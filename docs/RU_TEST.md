# Отдельная тестовая версия для телефона

**HoYo Assistant RU Test** устанавливается рядом с официальным приложением. Идентификатор тестовой копии — `danggai.app.resinwidget.rutest`, официальный — `danggai.app.resinwidget`.

Аккаунты, cookie, настройки, уведомления и виджеты хранятся отдельно. При первом запуске тестовая копия использует русский язык; сохранённый выбор языка можно изменить в настройках. В HoYoLAB нужно войти заново. Если проверяете автоотметку, учитывайте настройки этой функции в обеих копиях.

Вариант сборки называется `ruTest`. В нём отключены инициализация Firebase и отправка отчётов в Firebase исходного проекта, загрузка карты обфускации и загрузка рекламного баннера. Пустой контейнер баннера скрывается, поэтому область прокрутки занимает доступную высоту до системной панели навигации. Команды обновления виджетов используют идентификатор своего приложения.

## Сборка и подпись

На текущем компьютере JDK и Android SDK находятся в `I:\.codex\tools\android-localization`. Если используете другие пути, задайте `JAVA_HOME` и `ANDROID_HOME` перед запуском. Требуются JDK 21, SDK Platform 36 и Build Tools 34.0.0.

```powershell
.\scripts\build_ru_test.ps1 -VersionCode 1
```

По умолчанию подписанный APK и JSON с SHA-256 сохраняются в `artifacts/`. Этот каталог исключён из Git. Для другого каталога добавьте `-OutputDirectory`.

Скрипт использует уже созданный локальный ключ `hoyo-ru-test`, а не ключ автора приложения. Ключ и пароль не хранятся в репозитории. Пути по умолчанию:

- `I:\.codex\tools\android-localization\signing\hoyo-ru-test.p12`
- `I:\.codex\tools\android-localization\signing\hoyo-ru-test-password.txt`

Для другой машины передайте `-KeyStorePath` и `-PasswordFile`. Сохраните оба файла для будущих сборок: с другим ключом обновить уже установленную тестовую копию не получится.

## Следующие тестовые версии

После исправления перевода увеличьте тестовый номер:

```powershell
.\scripts\build_ru_test.ps1 -VersionCode 6
```

При сохранении того же ключа и идентификатора новый APK устанавливается поверх предыдущего **RU Test** с сохранением его данных. Официальное приложение продолжает обновляться независимо. Номер тестовой сборки не изменяет `Versions.versionCode` оригинальной конфигурации.

Исходники локализации: [инструкция по редактированию](LOCALIZATION_RU.md). Для APK после сборки доступны проверки `apksigner verify` и `zipalign -c`; сам скрипт выполняет их при подписании. Установка на телефон и работа с вашим аккаунтом проверяются отдельно.

Автоматическая публикация APK и выпуск GitHub Release не настроены.

## Размер шрифта подробных виджетов

В RU Test 5 основной текст подробных виджетов Genshin, Honkai: Star Rail и Zenless Zone Zero уменьшен с 12 до 10 sp. Новый размер используется в предпросмотре, в новых виджетах и при сбросе размера шрифта. Служебные подписи даты, имени и UID сохраняют размер 10 sp.

При первом запуске RU Test после обновления размер в сохранённых настройках подробных виджетов один раз устанавливается в 10 sp. Остальные свойства оформления копируются без изменений, а уже добавленным виджетам отправляется команда обновления интерфейса. Маркер миграции и обновлённый JSON настроек записываются одним редактором SharedPreferences. Повторные запуски не сбрасывают последующие ручные изменения размера.

Размер по умолчанию задают `Constant.PREF_DEFAULT_WIDGET_DETAIL_FONT_SIZE` и ресурс `widget_detail_text_size`. Настраиваемый пользователем размер по-прежнему имеет приоритет над XML-разметкой.
